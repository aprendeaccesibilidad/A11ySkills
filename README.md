# A11ySkills · prototipo de revisión experta (v35)

**Versión estática para GitHub Pages.** Derivada de A11ySkills v35.

## Publicación en GitHub Pages (sin Firebase)

1. Crea un repositorio público nuevo, por ejemplo `a11yskills-revision-expertos`.
2. Sube **el contenido de esta carpeta en la raíz del repositorio** (no la carpeta envolvente).
3. En `Settings > Pages > Build and deployment`, selecciona `Deploy from a branch`, rama `main`, carpeta `/(root)` y guarda.
4. Abre la dirección publicada que GitHub te indique. No inventes ni presupongas la URL.
5. Comprueba el recorrido de Exprés, el acceso Google **simulado**, el Reto completo, los 16 casos, las vistas móvil/PC y las animaciones.

GitHub Pages muestra páginas públicas: **conocer el enlace no es una protección de acceso**. Si tus casos o soluciones deben permanecer reservados, no publiques esta web en Pages y compártela para ejecución local por otros medios.

## Modo DEMOSTRACIÓN

- La cuenta Google es **ficticia**. No solicita contraseñas ni comunica datos a Google ni Firebase.
- Las respuestas se guardan mediante `localStorage` **solo en ese navegador y dispositivo**. No existe envío al equipo de investigación.
- Se presentan números ficticios en el Observatorio. **No son resultados científicos.**
- La evaluación de expertos debe recogerse en la ficha/hoja de validación facilitada por separado y entregarse por un canal institucional autorizado.
- Para acceder al Reto completo, haz el Exprés, finalízalo y vincula una cuenta ficticia en la demo.
- Evita introducir nombre real, correo, datos personales o información sensible en este prototipo.

## Qué contiene este paquete

- `index.html`: participación, Exprés, completo y vinculación Google simulada.
- `observatorio.html`: gráficos de demostración (datos ficticios).
- `sobre-el-proyecto.html` e `informacion-estudio.html`: información del proyecto.
- `*.js`, `styles.css`, `assets/`: recursos públicos necesarios.

## Qué NO se ha incluido deliberadamente

- `research_private/keys-v20.json` (solucionario WCAG); scripts de backend o privilegios.
- `admin.html` y archivos del panel administrativo.
- Configuración y módulos de conexión real a Firebase.
- Respuestas de usuarios o datos de investigación.

## Límites

- No utilizar este prototipo para reclutamiento o recogida de datos reales sin revisión de información y privacidad.
- Un enlace de Pages público no restringe la exposición de los casos WCAG.
- Si se modifica contenido, registra una nueva versión antes de comparar evaluaciones.
